Glossary

Short explanations of the words used in the rooms. Each entry says in which rooms you can see the idea at work.

Waves and arrows

Amplitude

A complex number that quantum mechanics gives to each possible way something can happen. Draw it as a small arrow: it has a length and a direction. To get a probability, add the arrows of all the ways, then square the length of the sum.

See it in: Every path is an arrow, Light takes every path.

Phase

The direction of an amplitude arrow, an angle from 0 to 360°. Only differences of phase can be measured. In the rooms, colour often shows phase: one full turn of the colour wheel is one full turn of the arrow.

See it in: Double slit flow, A phase without a force.

Probability

How often an outcome occurs when you repeat an experiment many times. In quantum mechanics it is the squared length of the total amplitude: P = |ψ|².

See it in: Double slit flow (the dots on the screen).

Interference

Two or more amplitudes add. If their arrows point the same way, the sum is long (bright). If they point in opposite directions, they cancel (dark). Interference makes the stripes in the double slit.

See it in: Double slit flow, The spinor flag, A phase without a force.

Superposition

A quantum state can be a sum of other states, for example "through the top slit" plus "through the bottom slit". The parts of a superposition can interfere.

See it in: Double slit flow, Order matters (cat states).

Wavelength

The distance over which the phase turns once. For a particle with momentum p, the de Broglie wavelength is λ = h/p. A faster particle has a shorter wavelength.

See it in: Double slit flow.

Wave function

The function ψ(x) that gives one amplitude for each position x. Its squared length |ψ(x)|² is the probability density to find the particle at x.

See it in: Double slit flow, Order matters.

Schrödinger equation

The equation that moves the wave function forward in time: iħ ∂ψ/∂t = Hψ. H is the energy operator (the Hamiltonian). The path integral gives the same results by a different route.

See it in: Double slit flow, A phase without a force.

Eigenstate (stationary state)

A wave that keeps its shape in time. Only its phase turns, with the rate set by its energy: φₙ(x)·e−iEₙt/ħ. Every wave is a sum of eigenstates. The interference of their turning phases makes the wave move.

See it in: Paths that meet again.

Born rule

The rule that connects the wave function to experiments: the probability to find the particle near x is |ψ(x)|². Each single measurement gives one definite result.

See it in: Double slit flow (each dot is one result).

Paths

Path integral

Feynman's way to do quantum mechanics. A particle goes from A to B by every possible path at the same time. Each path gives an arrow that turns by the action S of the path divided by ħ. Add the arrows of all paths: K(B,A) = Σpaths eiS/ħ.

See it in: Every path is an arrow, Light takes every path, Tunnelling in imaginary time.

Action

A number for each path: add up (kinetic energy − potential energy) along the path, over time. S = ∫ (½mv² − V) dt. In classical physics the real path is the one where S does not change for small changes of the path.

See it in: Every path is an arrow.

ħ (h-bar)

The reduced Planck constant, ħ = h/2π ≈ 1.055 × 10⁻³⁴ J·s. It sets the scale where quantum effects matter. An arrow turns once when the action changes by 2πħ. Many rooms let you change ħ to see what happens.

See it in: Every path is an arrow, Tunnelling in imaginary time.

Stationary phase

Near the path where the action does not change, neighbouring paths have arrows that point the same way, so they add up. Far from it the arrows turn quickly and cancel. This is why the sum over all paths is dominated by the classical path.

See it in: Every path is an arrow, Light takes every path (the mirror and Snell's law).

Classical limit

When the action is much larger than ħ, only paths very near the classical path survive the cancellation. Quantum mechanics then looks like Newton's mechanics. A thrown ball has an action of about 10³⁰ ħ.

See it in: Every path is an arrow (make ħ small).

Harmonic oscillator

A particle in the potential V = ½mω²x², like a ball on a spring. Every classical path has the same period T = 2π/ω, whatever its size. Its energy levels are equally spaced: Eₙ = ħω(n + ½).

See it in: Paths that meet again, The restless vacuum.

Gouy phase (Maslov phase)

An extra phase of −π/2 that a wave gets each time it passes through a focus, where many paths meet. In a harmonic trap the wave at half a period is the mirror copy times −i.

See it in: Paths that meet again.

Revival (Talbot effect)

A wave in a box comes back to its exact start shape after the revival time T_rev = 4mL²/(πħ), because all mode phases make whole turns. At simple fractions of T_rev the wave is a set of copies of the start wave. In optics the same effect behind a grating is the Talbot effect (1836).

See it in: Paths that meet again.

Imaginary time

A mathematical tool: replace time t by −iτ. The turning arrows eiS/ħ become positive weights e−SE/ħ. The quantum problem becomes a statistics problem that a computer can sample with random numbers. It is not a real time that you can measure.

See it in: Every path is an arrow, Tunnelling in imaginary time.

Wick rotation

The step from real time to imaginary time, done as a turn of the time axis by 90° in the complex plane. Results in imaginary time can often be turned back into real-time results.

See it in: Tunnelling in imaginary time (the θ slider).

Ground state

The state with the lowest possible energy. In quantum mechanics it is not at rest: the position still has a spread (zero-point motion).

See it in: Every path is an arrow, The restless vacuum.

Tunnelling

A quantum particle can cross a barrier that it does not have the energy to climb. In a double well, tunnelling splits the lowest energy level into two levels that are very close together.

See it in: Tunnelling in imaginary time, Every path is an arrow (double well).

Instanton

A path in imaginary time that jumps from one valley to the other. It is the classical solution of the upside-down potential. Each jump costs a factor e−S₀/ħ, so tunnelling is rare when the barrier is high.

See it in: Tunnelling in imaginary time.

Monte Carlo

A method that uses random numbers. It draws many random samples (here: random paths or random field values) with the correct weights, then averages over them. The error gets smaller like 1/√(number of samples).

See it in: Every path is an arrow, Broken symmetry, Phases around a loop.

Lattice

A grid of points that replaces continuous space or time, so that a computer can calculate. Fields live on the points; gauge fields live on the links between points. Good results need a grid that is fine compared with the sizes in the problem.

See it in: Phases around a loop, Vortices that trap flux, Pull two charges apart.

Measurement

Observable

A quantity that you can measure, such as position, momentum, energy or spin. In quantum mechanics it is an operator. The possible results are its eigenvalues.

See it in: Order matters.

Entanglement

Two systems share one quantum state that you cannot write as "a state of A" times "a state of B". Example: an electron and a marker, where "slit 1 and marker up" plus "slit 2 and marker down" is one state. Then a measurement on one system tells you about the other.

See it in: Watching the slits.

Decoherence

The loss of interference when a system leaves a record of itself in its surroundings (air molecules, light, a detector). The amplitudes still exist, but they can no longer meet and add, because the surroundings tell them apart. This is why big objects do not show interference.

See it in: Watching the slits.

Complementarity

You cannot have full which-path information and full interference stripes at the same time. In numbers: visibility V and distinguishability D obey V² + D² ≤ 1. More knowledge of the path means weaker stripes.

See it in: Watching the slits.

Quantum eraser

After a marker has recorded the path, read the marker in a way that does not tell the path. Sort the dots by that result, and each group shows stripes again. The total pattern still has no stripes, so nothing is changed in the past and no message is sent.

See it in: Watching the slits.

Measurement

A measurement gives one of the possible results, at random, with the probabilities of the Born rule. After the measurement the state is the state that belongs to that result. So a measurement can erase information from an earlier one.

See it in: Order matters (Stern–Gerlach in sequence).

Commutator

[A,B] = AB − BA. If it is zero, the order of A and B does not matter. For position and momentum, [x,p] = iħ: the order matters, and you cannot know both exactly.

See it in: Order matters.

Uncertainty principle

For position and momentum, Δx · Δp ≥ ħ/2. It follows from the commutator. It is a property of the state, not a fault of the measuring device.

See it in: Order matters.

Phase space

A map with position on one axis and momentum on the other. A classical particle is one point on this map. A quantum state is a smeared shape, at least ħ/2 in area.

See it in: Order matters.

Wigner function

A picture of a quantum state on phase space. It looks like a probability map, but it can be negative in small regions. Negative regions are a sign of a truly quantum state.

See it in: Order matters.

Spin and groups

Spin

An intrinsic angular momentum of a particle. An electron has spin ½: a measurement along any axis gives only "up" or "down".

See it in: The spinor flag, Order matters.

Spinor

The state of a spin-½ particle: two complex numbers. If you turn it by 360°, both numbers change sign. Only a turn by 720° brings it back exactly. Interference experiments with neutrons have measured this sign.

See it in: The spinor flag.

Bloch sphere

A sphere on which each spin-½ state is one point. North pole = up, south pole = down, points on the equator = sideways. The sphere does not show the overall sign of the spinor; the flag in the spinor room adds it.

See it in: The spinor flag.

Lie group

A smooth family of symmetry operations, such as all rotations. You can make every element from small steps; the directions of the small steps are the generators.

See it in: The spinor flag, Three colours.

Generator

A direction of small steps in a Lie group. U(1) has 1 generator, SU(2) has 3 (the Pauli matrices), SU(3) has 8 (the Gell-Mann matrices). In the Standard Model, each generator of a gauge group has one force particle.

See it in: Three colours.

U(1)

The group of turns of one arrow (multiplication by eiα). It is the gauge group of electromagnetism. The photon belongs to it.

See it in: Phases around a loop, A phase without a force.

SU(2)

The group of 2 × 2 unitary matrices with determinant 1. It turns spinors. It is the "double cover" of ordinary rotations: two elements of SU(2) give the same rotation. It is also the gauge group of the weak force.

See it in: The spinor flag.

SU(3)

The group of 3 × 3 unitary matrices with determinant 1. It mixes the three colour charges of a quark. It has 8 generators, one for each type of gluon. It is the gauge group of the strong force.

See it in: Three colours.

Gauge fields

Gauge symmetry

You can turn the phase of the wave function by a different amount at each point, and the physics does not change, if a gauge field changes at the same time to compensate. Only quantities that do not change, such as the phase around a closed loop, can be measured.

See it in: Phases around a loop, A phase without a force (move the cut line).

Gauge field

The field that tells a charged particle how much its phase turns when it moves from one point to the next. The electromagnetic potential is a U(1) gauge field; the gluon field is an SU(3) gauge field. On a lattice it is one phase (or one matrix) per link.

See it in: Phases around a loop, Vortices that trap flux.

Vector potential

The electromagnetic gauge field A. A charge q that moves along a path picks up the extra phase (q/ħ) ∫ A · dl. The magnetic field is the "curl" of A.

See it in: A phase without a force.

Magnetic flux

The total magnetic field that goes through a surface, Φ. By Stokes' theorem it equals the loop sum of the vector potential around the edge of the surface. So the extra phase around a loop measures the flux inside.

See it in: A phase without a force, Vortices that trap flux.

Flux quantum

The flux that turns the phase of a charge by exactly one full turn: Φ₀ = h/q. In a superconductor the charge carriers are pairs (q = 2e), and each vortex holds exactly one flux quantum h/2e.

See it in: A phase without a force, Vortices that trap flux.

Wilson loop

The total phase that a charge picks up around a closed loop. It does not change under gauge transformations, so it is physical. If its average falls with the area of the loop, the force between two charges grows with distance: confinement.

See it in: Phases around a loop.

Confinement

Quarks are never seen alone. The energy between a quark and an antiquark grows with their distance, like a string. This is a property of QCD in our 4D world. The rooms show simpler models with the same behaviour.

See it in: Phases around a loop, Pull two charges apart.

String tension

The energy per length of the flux tube between two confined charges. For quarks it is about 0.9 GeV per femtometre (1 fm = 10⁻¹⁵ m). As a force, this is about 140 000 newtons: the weight of about 14 tonnes.

See it in: Phases around a loop, Pull two charges apart.

Quark

A matter particle that feels the strong force. Protons and neutrons contain three quarks each. Each quark carries one of three colour charges.

See it in: Three colours.

Colour charge

The charge of the strong force. It has three values, called red, green and blue (only names; nothing to do with real colour). SU(3) turns the three colours into each other. Only colour-neutral combinations exist alone.

See it in: Three colours.

Gluon

The force particle of the strong force. There are 8 types, one for each generator of SU(3). Gluons carry colour themselves, so they attract each other. This is the main difference from the photon.

See it in: Three colours.

Symmetry breaking

Spontaneous symmetry breaking

The laws have a symmetry, but the lowest-energy state does not. A ball at the top of a Mexican hat is symmetric, but it rolls down into the valley in one direction.

See it in: Broken symmetry.

Goldstone mode

Motion along the valley of the Mexican hat. It costs no energy for long waves, so its frequency goes to zero. Sound waves in a crystal and spin waves in a magnet are Goldstone modes.

See it in: Broken symmetry.

Higgs mode and Higgs mechanism

The Higgs mode is the oscillation up and down the wall of the Mexican hat. The Higgs mechanism happens when the broken symmetry is a gauge symmetry: the Goldstone mode is absorbed by the gauge field, and the force particle becomes heavy. In a superconductor this makes the magnetic field short-range.

See it in: Broken symmetry, Vortices that trap flux.

Vortex

A point (in 2D) around which the phase of a field turns by a whole number of full turns. At the centre the field must be zero. Vortices appear in superfluids, superconductors and magnets.

See it in: Broken symmetry, Vortices that trap flux.

Winding number

How many full turns the phase makes on a loop around a point. It is a whole number. You cannot change it by small smooth changes, so vortices are stable.

See it in: Broken symmetry, Vortices that trap flux.

Kosterlitz–Thouless transition

In a 2D field of compass needles, vortex–antivortex pairs stay bound at low temperature and come apart above a critical temperature (about 0.89 in the room's units). Kosterlitz and Thouless received the 2016 Nobel Prize in Physics, together with Haldane, for this kind of work.

See it in: Broken symmetry.

Superconductor

A metal in which electron pairs form one quantum state with one phase. It carries current without resistance and pushes out magnetic fields. In type II superconductors the field enters in thin vortices, each with one flux quantum.

See it in: Vortices that trap flux.

Fields and vacuum

Field

A quantity that has a value at every point of space, such as temperature or the electric field. On a lattice it has one value per grid point.

See it in: The restless vacuum, Broken symmetry.

Quantum field

A field whose value at each point is quantum: it has a spread, like the position of a quantum particle. Particles are the small ripples (quanta) of the field. In the Standard Model every particle type has its own field.

See it in: The restless vacuum, Feynman diagrams from a path integral.

Vacuum

The ground state of all the quantum fields: no particles. The field values still have a spread. The vacuum also responds when you change its boundaries, for example with two plates.

See it in: The restless vacuum, Pull two charges apart.

Zero-point energy

Each wave mode of a quantum field keeps the energy ½ħω even in the ground state. The total is infinite, but differences of it are finite and measurable.

See it in: The restless vacuum, Paths that meet again.

Casimir effect

Two conducting plates close together in vacuum attract each other. Between the plates fewer wave modes fit, so the zero-point energy changes with the distance. Measured precisely since 1997.

See it in: The restless vacuum.

Feynman diagrams and the Standard Model

Scattering

A particle comes in, meets an obstacle (a potential), and goes out. In one dimension it can only go through (transmission, amplitude t) or bounce back (reflection, amplitude r). Probability is conserved: |t|² + |r|² = 1.

See it in: Feynman diagrams for a real particle.

Born series and Born approximation

Write the scattered wave as: no kick, plus one kick by the potential, plus two kicks, and so on. Each term is a Feynman diagram with that many vertices. Keeping only the first kick is the Born approximation. The series converges only when the potential is weak enough.

See it in: Feynman diagrams for a real particle.

Bound state

A state in which an attractive potential holds the particle, so it cannot fly away. Its energy is below the energy of a particle at rest far away. If a potential can hold a bound state, the Born series fails at low energy.

See it in: Feynman diagrams for a real particle.

Resonance

At some energies the waves that bounce back and forth inside a potential add up in step. Then the particle goes through completely (|t|² = 1), even through a barrier or past a well.

See it in: Feynman diagrams for a real particle.

Propagator

The amplitude for a particle to go from one point to another: the sum over all paths between them. In a Feynman diagram, each line is a propagator.

See it in: Every path is an arrow, Feynman diagrams from a path integral, Paths that meet again.

Feynman diagram

A drawing that stands for one term in a calculation. Lines are propagators, and points where lines meet are vertices. Each diagram gives one amplitude; add the diagrams to get the total amplitude.

See it in: Feynman diagrams from a path integral.

Vertex

A point in a Feynman diagram where particles meet, for example where an electron emits a photon. Each vertex brings one factor of the coupling.

See it in: Feynman diagrams from a path integral.

Coupling

A number that sets the strength of an interaction. In QED the fine-structure constant α ≈ 1/137 is small, so diagrams with many vertices are small corrections.

See it in: Feynman diagrams from a path integral, Vortices that trap flux.

Perturbation theory

Start from a problem that you can solve exactly (free particles), then add the interaction as a series of small corrections: one vertex, two vertices, and so on. Each term is a set of Feynman diagrams. The series usually does not converge, but its first terms are very accurate when the coupling is small.

See it in: Feynman diagrams from a path integral.

QED (quantum electrodynamics)

The quantum theory of electrons, positrons and light. Its predictions agree with experiment to about 10 digits, for example for the magnetic moment of the electron.

See it in: Light takes every path, Feynman diagrams from a path integral.

Schwinger model

QED in one space dimension. It is simple enough to solve on a computer, but it shows confinement and string breaking, like QCD.

See it in: Pull two charges apart.

QCD (quantum chromodynamics)

The quantum theory of quarks and gluons, with gauge group SU(3). It explains why protons hold together and why quarks are confined.

See it in: Three colours, Phases around a loop.

Standard Model

The theory of all known particles and forces except gravity. Its gauge group is SU(3) × SU(2) × U(1): the strong force, the weak force and the electromagnetic force (after the Higgs mechanism). It has 12 force particles: 8 gluons, W⁺, W⁻, Z and the photon.

See it in: Three colours, The spinor flag, Phases around a loop.
