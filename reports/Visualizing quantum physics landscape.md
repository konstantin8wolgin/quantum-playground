# Browser gaps decide what the quantum museum builds

The best targets are the places where no good browser demo exists. Real-time path sums, imaginary-time sampling, lattice gauge theory with Wilson loops, the Abelian Higgs step (a Goldstone mode eaten by a gauge field), and a live confinement picture all have no polished, open, browser-native version in the notes. The existing demo `demos/path-integral.html` already fills the first two gaps. The quantum-mechanics basics, Ising and XY models, Bloch spheres and Hopf fibrations do exist, mostly as old Java, Flash, Wolfram or video material. Code reuse is thin. Only a few items have clear permissive licences: kjslag/XY (MIT), radames/Ising-Model-WebGL (MIT) and mwalczyk/hopf (CC BY 4.0). So the project should write every shader fresh and take only ideas and equations from others. The recommended museum has four layers and eleven more single-file WebGL2 demos. Each demo shows one number that a test checks against an exact answer. The build order puts cheap, striking demos first: a spinor demo for the 720-degree rule, a double slit with phase colour, and an XY vortex page. It ends with the Abelian Higgs and string-breaking demos. Those two are the hardest, and they match your stated goal best. Numbers marked "standard result" below come from textbook physics, not from the research notes. Check them in code before you publish.

## What exists today, and where the holes are

**Path integrals.** Real-time treatments exist as GeoGebra pages ([GeoGebra Young](https://www.geogebra.org/m/GALGGPlo), [GeoGebra sum over paths](https://mat.geogebra.org/m/PEfGzNVN)), a Maple worksheet ([York U](https://www.yorku.ca/marko/ComPhys/FraunhoferFeynman/FraunhoferFeynman.html)) and Taylor's teaching software ([Taylor OnePhoton](https://www.eftaylor.com/software/OnePhotonExercises.pdf)). The notes found no modern browser demo with a Cornu spiral and stationary phase. Imaginary-time material is lecture notes, notebooks and old Java: a ring-polymer tutorial ([Vesely](https://homepage.univie.ac.at/franz.vesely/cp_tut/nol2h/new/c7qm_s2pim.html)), a course project ([Illinois PHYS466](https://courses.physics.illinois.edu/phys466/sp2011/projects/2007/team_pimc/pimc.html)), a Jupyter lab ([UCSD Lab 15](https://jduarte.physics.ucsd.edu/phys142/labs/lab15/Lab15.html)) and a gated tool ([nanoHUB](https://nanohub.org/resources/3690)). Double-well instantons appear in lattice papers with cooled paths overlaid ([hep-lat/0411010](https://arxiv.org/pdf/hep-lat/0411010)), but no interactive version turned up. Your demo already fills the Cornu-spiral gap and the imaginary-time sampler gap, including the exact transfer-matrix check. Four path-integral gaps stay open. First, no demo morphs real time into imaginary time with a Wick-rotation slider. Second, no page shows an instanton as a cooled path. Third, no page shows Feynman-Kac weighting of a Brownian cloud by a painted potential. Fourth, no page builds a double slit from paths.

**Quantum-mechanics basics.** Wave-packet and slit simulators are plentiful. marl0ny has WebGL split-operator and Crank-Nicolson simulators ([marl0ny](https://marl0ny.github.io), [QM-Simulator-2D](https://github.com/marl0ny/QM-Simulator-2D)). Schroeder has HTML5 apps for wave packets, spins and entanglement ([Schroeder](https://physics.weber.edu/schroeder/software)). QuVis offers 90+ research-based simulations ([QuVis](https://st-andrews.ac.uk/physics/quvis/about.html)). PhET has an HTML5 wave-interference simulation ([PhET](https://phet.colorado.edu/en/simulations/quantum-wave-interference)). Thaller's CD-ROM made the phase-colour wheel for wave functions popular ([Springer](https://link.springer.com/book/10.1007/b98962)). The holes are sharper. The notes found no in-browser Bohmian double slit; the only hits are Wolfram Demonstrations and papers ([Wolfram](https://demonstrations.wolfram.com/TripleSlitExperimentInTheCausalInterpretation/)). Commutators have no widely known intuitive demo; Schroeder's linked Stern-Gerlach lab is the closest ([Schroeder](https://physics.weber.edu/schroeder/software)). Wigner functions live in Python galleries ([QuTiP](https://nbviewer.hrz.uni-marburg.de/github/jrjohansson/qutip-lectures/blob/master/Lecture-16-Gallery-of-Wigner-functions.ipynb), [TU Delft](https://interactivetextbooks.tudelft.nl/qsm/src/5_wigner_2.html)), with no JavaScript demo of coherent, squeezed or cat states. The notes did not search PhET or QuVis catalogues for a commutator page, so treat that gap as likely, not proven.

**Fluctuations and lattice fields.** Ising and XY have good demos. kjslag/XY is a WebGL XY model with mouse-driven vortices ([kjslag](https://github.com/kjslag/XY)). An ibiblio WebGL2 Ising page uses checkerboard updates ([ibiblio](https://ibiblio.org/e-notes/Perc/ising.htm)). A WebGPU 3D Ising page scans temperature ([skal65535](https://skal65535.github.io/ising/index.html)). The notes found no browser lattice phi^4 demo, no free-field vacuum demo and no Casimir simulator. Linde's chain-of-oscillators picture gives the right intuition for free fields but has no code in the notes ([arXiv 1907.11311](https://arxiv.org/abs/1907.11311)). Lattice gauge theory is the biggest hole. Leinweber's Adelaide visualisations are the gold standard, but they are videos and GIFs ([arXiv:hep-lat/0004025](https://ar5iv.labs.arxiv.org/html/hep-lat/0004025), [arXiv:1903.08308](https://ar5iv.labs.arxiv.org/html/1903.08308)). The notes found no browser lattice gauge Monte Carlo with Wilson loops. A page named "Wilson Loop Lab" returned a 404, so it is unverified ([Elysiatools](https://elysiatools.com/en/math/wilson-loop)). One warning from Leinweber matters for any cooling demo: instantons seem to shrink under cooling, but that reading is wrong ([arXiv:hep-lat/0004025](https://ar5iv.labs.arxiv.org/html/hep-lat/0004025)).

**Lie groups and gauge phases.** SU(2) has the richest material: Egan's belt-trick applet ([Egan](https://gregegan.net/APPLETS/21/21.html)), Palais's visualiser ([Palais](https://www.math.utah.edu/~palais/JavaBeltPlateQuat/belt.html)), 3Blue1Brown's quaternion lesson ([3b1b](https://www.3blue1brown.com/lessons/quaternions)), and Johnson's Hopf video ([Johnson](https://nilesjohnson.net/hopf)). Most are video or Java. The notes found no browser-native belt trick and no spinor flag demo. For SU(3), the notes list a weight-diagram web app ([su3_reps](https://rl596.user.srcf.net/su3_reps)), a Jupyter notebook ([SU3-multiplets](https://github.com/giochanturia/SU3-multiplets)) and a teaching paper with VPython ([arXiv 1907.12520](https://arxiv.org/abs/1907.12520)). No source shows what an SU(3) element does to a colour triplet, and no source shows three Bloch spheres, one per colour pair. U(1) has no dedicated visual; the best idea (a local phase twist cancelled by a gauge field) is untried. Aharonov-Bohm has one browser simulator of unknown quality ([Elysiatools](https://elysiatools.com/en/visualizations/aharonov-bohm)) and a Wolfram demo ([Wolfram](https://demonstrations.wolfram.com/AharonovBohmEffect/)). No web demo shows parallel transport or a lattice connection.

**Symmetry breaking and confinement.** The notes found no browser demo of the Abelian Higgs mechanism. The Cambridge Higgs Simulator is a scalar-field tool, not a gauge model ([Cambridge](https://www.hep.phy.cam.ac.uk/~lester/higgs-simulator/manual.pdf)). A "quark confinement" page loads by iframe and the notes could not assess it ([Homo Deus Lab](https://homo-deus-lab.pages.dev/lab/particle-physics/quark-confinement/)). Confinement material is mostly Leinweber's animations and one Wikipedia string-breaking animation ([Wikipedia](https://en.wikipedia.org/wiki/Color_confinement)). Strassler explains what the pictures must avoid. The molasses and crowd analogies break relativity and Newton's laws ([Strassler 2024](https://profmattstrassler.com/2024/04/16/why-the-higgs-field-is-nothing-like-molasses-soup-or-a-crowd/)). Virtual particles are calculation lines, not things that pop in and out ([Strassler 2011](https://profmattstrassler.com/2011/10/10/virtual-particles-not-particles-at-all/)). The physics also has open points. One paper treats the superconductor Goldstone mode as the plasmon; another disputes this ([arXiv 2008.08799](https://arxiv.org/pdf/2008.08799), [arXiv 1906.02097](https://arxiv.org/pdf/1906.02097)). A demo must not call that point settled.

The production lattice codes QUDA, SIMULATeQCD and Grid are CUDA or C++ and cannot enter a browser file. Use them for algorithm checks only ([QUDA](https://github.com/lattice/quda), [SIMULATeQCD](https://arxiv.org/pdf/2306.01098), [Grid](https://arxiv.org/pdf/2203.06777)). The notes could not search GitHub directly, so small repos may be missing. Run `gh api repos/<owner>/<repo>/license` on any repo before you reuse it.

Your `PROMPT.md` says "no external libraries". That rule also removes the licence problem. Write raw WebGL2 for every demo. Use the equations in the papers and credit them in a footer. The technical notes support this. WebGL2 has **97.29%** global support and works from a double-click ([caniuse WebGL2](https://caniuse.com/webgl2)). WebGPU has **88.63%**, and Firefox on Linux and Android is still not stable ([caniuse WebGPU](https://caniuse.com/webgpu), [web.dev](https://web.dev/blog/webgpu-supported-major-browsers)). So WebGPU can be a bonus, never the base. The standard recipe is ping-pong RGBA32F textures with `EXT_color_buffer_float`, checkerboard passes, and a per-site hash RNG such as PCG. Updating all sites at once is invalid ([arXiv cs/0312006](https://arxiv.org/pdf/cs/0312006)). The ibiblio page uses an LCG, which has weak low bits. For gauge links, use Z_N or U(1) angles first, then SU(2) as a quaternion with four floats. SU(3) is heavy in a fragment shader, so keep it to the triplet action and the weight diagram. Use Metropolis plus overrelaxation, not heat-bath, because heat-bath needs rejection loops. The last four rules (hash RNG, quaternion links, no SU(3) Monte Carlo, Metropolis plus overrelaxation) are the note authors' engineering judgement, not tested results.

## The most striking ideas, ranked by gap size and visual power

The ranking uses three tests. Does the idea fill a gap? Does it show one thing that the eye can see and the code can check? Does it avoid a known misconception? Each check number below is a standard result unless a source is given.

The first idea is the **Higgs step in a live field**. A 2D lattice has a complex scalar and a U(1) gauge field. A slider turns the gauge coupling on and off. With coupling off, a long phase wave (the Goldstone mode) travels freely and an applied magnetic field passes through. With coupling on, the wave disappears and the field dies within the London depth. Vortices carry quantised flux. The notes call this exact picture missing from browsers, and it ties a Lagrangian feature to a visible change, which is the shared complaint in the notes. The check number is the field decay length, 1/(e v) in lattice units, compared with a fit. It is the hardest demo of the set, so it comes last. Label the superconductor link as an analogy and avoid the disputed plasmon claim.

The second idea is **2D compact U(1) with Wilson loops**. Each link holds a phase. A Wilson loop is the phase picked up along a path, so this demo says "gauge field as phase along a path" literally. In 2D with the Wilson action, the loop average is exactly (I1(beta)/I0(beta)) raised to the loop area, so the string tension is sigma = -ln(I1/I0) (standard result, unsourced). The Monte Carlo must match it. In 4D the known number is the first-order transition at beta_c = **1.0111331(21)** ([arXiv:hep-lat/0503024](https://arxiv.org/pdf/hep-lat/0503024)), but 4D needs slices and careful hysteresis work, so start in 2D. The plaquette-angle colour map also gives an integer topological charge in 2D.

The third idea is the **spinor and 720-degree page**. One unit quaternion drives four linked views: a rotating 3D object, a Bloch sphere with a Penrose flag, a stereographic S3 point, and the path in SU(2) next to its image in SO(3). The notes call the flag-on-Bloch-sphere view an uncovered gap. A 360-degree turn flips the flag, and 720 degrees restores it. The check is a pure number: the state returns only at 4 pi. A belt or ribbon page can follow, built from a slerp-scaled frame along arc length, as in Egan and Palais. A Hopf explorer can follow too, where dragging a Bloch point shows the phase-circle fibre.

The fourth idea is **SU(3) as action, then as weights**. Three phasor wheels show a colour triplet, with one hold-to-flow button per Gell-Mann generator. The generators lambda_3 and lambda_8 only turn phases. The other six mix pairs. Three small Bloch spheres, one for each colour pair, show the three SU(2) subgroups. A second page shows the (I3, Y) weight diagram, where quarks sit at u (1/2, 1/3), d (-1/2, 1/3), s (0, -2/3) ([SJSU](https://www2.sjsu.edu/faculty/watkins/particle.htm)). Clickable root vectors move states, and 3 x 3bar gives 8 plus 1. The literature advises "visualise the action, not the group" ([PhysicsOverflow](https://physicsoverflow.org/40215)). The check is the product rule: the triplet-times-antitriplet decomposition must give dimensions 8 and 1.

The fifth idea is a **double slit with phase colour and probability-current streamlines**. A split-operator solver in WebGL2 runs the packet. The streamlines follow v = (hbar/m) Im(grad psi / psi). The notes found no in-browser version of this pairing. The check is norm conservation to a tight tolerance, plus fringe spacing against the standard far-field formula. It also links to your path-integral demo: the same pattern appears from summed arrows.

The sixth idea is the **phase-wheel XY lattice**, with a quench-rate slider. Vortices show up where all colours meet. The kjslag demo has no quench control, and no browser Kibble-Zurek demo exists in the notes ([arXiv 2105.11680](https://arxiv.org/pdf/2105.11680v3)). The check is the Kosterlitz-Thouless point near T = 0.893 J (standard result). Pair it with a Mexican-hat page where radial ringing is the Higgs mode and tangential motion is the Goldstone mode. A 1D spin chain shows the Goldstone mode as a long wave.

The seventh idea covers **commutators and uncertainty** in a "measurement order" sandbox. A Stern-Gerlach chain (z, then x, then z) shows that order matters. A side panel shows a live Wigner function with a negative region for a Fock or cat state. The check is [x, p] = i hbar, found from a finite-difference operator, plus the uncertainty product hbar/2 for a Gaussian. For the n = 1 Fock state, W(0) = -1/(pi hbar) (standard result).

The eighth idea is **vacuum fluctuations and the Casimir effect**. A free scalar field is sampled exactly by FFT with variance 1/(2 omega_k), so no Monte Carlo is needed. Plates restrict the modes, and the energy per area follows from a regulated mode sum. In 1+1D the check is E = -pi hbar c / (24 d). In 3D it is -pi^2 hbar c / (720 d^3) (both standard results, unsourced). Show a chain of oscillators, not "particles popping in and out", to follow Strassler's warning.

The ninth idea is **string breaking** in a Schwinger-style 1+1D cartoon. Drag two quarks apart. The energy rises linearly, then the tube snaps into two mesons ([arXiv 2509.03586](https://arxiv.org/pdf/2509.03586)). Label it a cartoon of the Cornell potential V(r) = -4 alpha_s/(3 r) + sigma r ([Wikipedia](https://en.wikipedia.org/wiki/Color_confinement)). The check is the linear slope equal to the string tension from demo two. A simplified Lund fragmentation can follow, checked against Pythia output ([arXiv 1808.04619](https://arxiv.org/pdf/1808.04619)).

Three more ideas fit the existing demo. A Wick-rotation slider would turn t into -i tau and morph oscillating arrows into decaying weights. That page would be new, per the notes. A Feynman-Kac cloud would show Brownian paths weighted by a painted potential, with the ground state appearing. Cooled-path instantons would overlay on the double-well sampler. Reuse the existing Metropolis and transfer-matrix code for all three.

## A four-layer museum, built in an order that pays off early

The structure follows Bret Victor's ladder of abstraction: start simple, give direct control, link several views, and keep a concrete view always visible ([Victor](https://worrydream.com/LadderOfAbstraction/)). Distill adds predict-then-reveal prompts and details on demand, and warns that not everything needs interactivity ([Distill](https://distill.pub/2020/communicating-with-interactive-articles/)). PhET interviews give practical rules. Students treat every visual feature as important, so show only what carries the lesson. Written help bubbles failed. A simple slider needed no instruction. A cue such as a pulsing handle fixed the "what can I drag" problem ([PhET Part II](https://phet.colorado.edu/publications/archive/PhET%20interview%20Paper%20Part%20II.pdf)). Slider limits should show extreme cases ([arXiv 1306.6544](https://arxiv.org/pdf/1306.6544)). Visual choices can plant misconceptions, as the single-photon study shows ([arXiv 1410.0867](https://arxiv.org/pdf/1410.0867)). Each demo page should have the same five rungs: a striking calm start with one or two controls, a predict prompt, a linked abstract view, equations in a `<details>` block, and raw parameters with the check number. The notes did not verify exemplars such as Nicky Case or Red Blob Games, so use them as taste references only.

Layer labels: A paths, B quantum basics, C groups and phases, D breaking and confinement, E fields and lattices. The order has two logic rules. Cheap and striking demos come first, so the museum has a strong front door early. Demo 7 comes before demo 11 because string breaking reuses its string tension, and demo 3 comes before demo 10 because the Higgs page reuses the XY lattice. Demos 6, 7 and 10 share one visual language, U(1) phases on links, as the notes observe. Build that shared lattice shader once.

Shared technical rules come from the notes. Use one HTML file per demo and one landing page of cards with relative links. Avoid `fetch()` of local files and Web Workers from `file://`. Cap devicePixelRatio near 2. Pause when the tab is hidden. Set `touch-action: none` on canvases. Handle `webglcontextlost`. Start paused under `prefers-reduced-motion`. Use native range sliders for keyboard access. Avoid red-green palettes. Use the same colour for the same quantity in every demo. Give each page a plain-text description and a dark and light theme, as `PROMPT.md` requires. For the recording goal, an in-page Record button can use `canvas.captureStream` with MediaRecorder, which has been Baseline since April 2021 ([MDN](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder)). GitHub Pages hosts the folder free from a public repo ([GitHub Docs](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)). Keep `PROMPT.md` and `DATA.md` current per your sharing rule.

## Conclusion

The research changes the plan in one way. The museum should not copy the field; the field is mostly old applets and videos with unclear licences. It should win where the gaps are: gauge fields as phases along paths, and a slider that connects a Lagrangian feature to a visible change. The Wilson-loop page and the Higgs page do that. A path integral, a lattice phase and a gauge-field Higgs page are three views of the same object, a sum over phases, and the museum can say so.

Two risks remain. The physics checks marked "standard result" have not yet run in code, and the Abelian Higgs and string-breaking demos have no verified source for their exact lattice set-up. Test each check number in a script before you publish a demo. Also, search was shallow in places. The notes did not cover GitHub, Shadertoy, Observable, PhET and QuVis catalogues, or the main intuition texts (Feynman's QED, Zee, Susskind), so treat "no demo found" as "not found", not "does not exist".
