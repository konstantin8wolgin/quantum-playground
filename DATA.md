# Data

All data in this project is generated by the demos themselves (seeded random
numbers). No external data set is used yet.

- Exact reference values come from closed formulas (harmonic oscillator:
  ⟨x²⟩ = ħ/(2mω)·coth(βħω/2)) or from a numerical transfer matrix on a grid.
- If an external data set is added later (for example particle data), list the
  source and licence here and put the file in `data/`.
